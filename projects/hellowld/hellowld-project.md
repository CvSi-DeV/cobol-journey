# Hello World — Progress Tracker

## Apprentissage

- Structure d'un programme : 4 divisions
  - Identification
  - Environment
  - Data
  - Procedure
- Position 7 pour déclarer un commentaire ou une continuation
- Position 8 : début de la zone A
- Position 12 : début de la zone B
- Instruction `DISPLAY`
- 3 manières de terminer un bloc / une exécution :
  - `STOP RUN.`
  - `GOBACK`
  - `EXIT PROGRAM`
- Le point (`.`) termine les instructions
- Pour terminer un programme, la clause `END PROGRAM nom-pgm.` doit reprendre le même nom que la clause `PROGRAM-ID` de la division `IDENTIFICATION`.

## Challenge

- Installer l'environnement
- Mettre en œuvre le premier programme

## Temps

- 2h de lecture
- 2h de manipulation
- Le Hello World est facile à implémenter.
